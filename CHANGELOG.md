# Changelog

All notable changes to Shift Checklist are recorded here.

## 0.1.0 — 2026-08-02

- Added the local Today checklist, task-template management, and immutable shift
  history.
- Added manual Shopify work with priorities and workflow statuses.
- Added scheduled task and repeated client-message reminders with Windows and
  in-app delivery.
- Added configurable reset timing, reminder behavior, sounds, and categories.
- Added versioned atomic JSON storage, backup recovery, and rotating local logs.
- Added empty, typical, and large-dataset smoke validation and Windows packaging.
